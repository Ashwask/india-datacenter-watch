# How india-datacenter-watch follows PDGI

A community-accountability map of ~191 data centres across India. Built on **People's Digital Goods & Infrastructure (PDGI)** principles — people before digital, rights-centric, commons-oriented, transparent ([pdgi.org](https://pdgi.org/)).

This is a public scorecard of how those principles are implemented here, with honest notes on where it falls short. It was generated from a repository audit (2026-07); update it as the code changes.

**License:** MIT · **Live:** https://ashwask.github.io/india-datacenter-watch

Status key: ✅ implemented · 🟡 partial · ⛳ gap · — not applicable.

## Scorecard

### People before digital — ✅
Centres the community, energy and water impact of the data-centre buildout on residents.

### Transparency and accountability — ✅
A source URL is required per facility; estimate formulas are transparently labelled.

### Decentralisation and no lock-in — ✅
Download CSV (filtered or full); open CSV + schema; an optional read-only API.

### Free software and the digital commons — ✅
MIT; a static no-build site; the full dataset + build script are public.

### Privacy — ✅
No trackers; the report form posts a GitHub Issue; private fields are kept out.

### Platform cooperativism — ✅
A PR + website report flow; a community_reported tier; reviewed promotion.

### Humans in the loop (AI does not cut people out) — —
No AI / algorithmic component.

### A non-digital alternative — ⛳
An interactive map only; no printable / offline directory.

### Grassroots and reaching the divide-affected — ⛳
English-only; no vernacular for the affected host communities. Direction: vernacular layer.

### Algorithmic fairness — —
A descriptive map, not a scoring algorithm.

**Overall:** 6✅ 0🟡 2⛳
